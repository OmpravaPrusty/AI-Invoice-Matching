AI Invoice Matching - Project Overview
1. Introduction
The AI-Powered Purchase Order & Invoice Matching System is a web-based application designed to automate the comparison of Purchase Orders (POs) and Supplier Invoices using Artificial Intelligence.
The system extracts key information from uploaded documents, compares them intelligently, identifies discrepancies, and generates a comparison report. It helps small and medium-sized businesses reduce manual verification effort, minimize errors, and speed up invoice validation before payment approval.

2. Objective
Develop an AI-powered web application that enables users to upload Purchase Orders and Invoices, automatically extract document data, compare both documents, detect discrepancies, and generate an easy-to-understand comparison report.
