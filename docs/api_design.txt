API Design Document
AI Invoice Matching 

1. Overview
The application follows a RESTful API architecture.
The frontend communicates with the FastAPI backend using JSON-based REST APIs. The backend handles authentication, document upload, OCR processing, AI extraction, comparison logic, database operations, and report generation.

2. Authentication APIs
Login
POST
/api/auth/login

Request
{
  "email": "user@example.com",
  "password": "password123"
}

Response
{
  "access_token": "...",
  "token_type": "Bearer"
}


Get Current User
GET
/api/auth/me

Returns logged-in user information.

Logout
POST
/api/auth/logout

Invalidates the current session/token (implementation dependent).
